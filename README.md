# I See Me

心理课作业的 3D 镜头叙事 Demo：经历情境，观察自己，再观察正在观察的自己。

> 课堂流程已按 0–11 时序实现（三条分支、第一人称自由转头、L2 第三人称回看）；
> 人物与教师动效、桌面道具为程序化生成的低多边形占位，尚无配音与正式音效。
> 骨架自测不代表完整试玩与情绪强度验收已完成。

## 已确定的方向

- Godot 4.6.1 标准版、GDScript、Compatibility 渲染器。
- 只保证 Windows x64，简体中文，键鼠操作，离线运行。
- 一个教室事件、线性五个环节、单一分支点的三条分支，固定收束。
- 风格化低多边形；优先免费可用素材；AI 配音在制作阶段生成。
- 七人协作，你承担主开发与集成，其余六人按实际参与制作分工。
- 四周安排，每人每周约 3–5 小时；主开发的实际投入另行确认。

## 获取项目

```powershell
git clone https://github.com/clcloudy/i-see-me.git
cd i-see-me
```

私有仓库的成员需先获得访问权限，并使用自己的 GitHub 账号。
仓库所有者本机已部署在 `D:\tools\Godot\4.6.1`，可直接双击 `打开编辑器.cmd` / `查看房间.cmd`；
其他成员需自行部署同版本引擎。启动、检查与截图的完整命令见[本机部署与启动](docs/setup.md)。

课堂对话场景 `scenes/classroom_dialogue.tscn` 可在编辑器里按 **F6** 单独运行。
当前没有音源，静音只验证了总线状态；正式声音接入后仍需重新验证。

## 开工前需要补齐

- 在开发计划中填写成员姓名、GitHub 用户名。
- 按协作规则完成每个人的第一次小样、提交与合并练习。
- 本周后续安装匹配版本的导出模板并验证目标电脑；当前尚未配置 Windows 导出。
