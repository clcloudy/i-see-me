I See Me — 课堂 Demo 0.1.0
Windows x64 / 简体中文 / 键盘与鼠标 / 离线运行

启动
1. 将整个 ZIP 解压到一个文件夹。
2. 双击 I See Me.exe。不需要安装 Godot 或 .NET。
3. I See Me.exe 和 I See Me.pck 必须放在同一个文件夹，请勿只发送 exe。

操作
鼠标点击界面按钮和观察提示；按住鼠标左键或右键拖动，或用方向键转头。
回答框出现时可以输入想说的话；也可以不填，不需要提供真实经历。
Esc 暂停 / 继续；界面提供静音、跳过、重开和退出。
跳过只推进当前片段；回答仍由玩家自行选择或提交。

第二层可逐人回看课堂事件，填写当时的想法，也可留空或跳过。
第三层包含可跳过的心理学说介绍，离线可回看自己的原文。
如选择在线 AI 分析，需在游戏内填写自己的 DeepSeek API 密钥，并明确确认发送。
在线请求会将待发送预览中的课堂事件、想法与感受交给 DeepSeek 处理，需联网且可能产生服务费用。
密钥只保留在本次运行内存中，每次启动重新填写。分析是 AI 的暂定理解，可拒绝或补充。

内容提示与当前范围
包含课堂点名、回答压力、同学议论与不同意见，可随时停止体验。
这是当前课堂主流程、第二层输入与第三层回看的 Demo 发行构建，含占位内容与部分配音，
并非完整正式游戏，也不提供心理诊断或结局评级。
部分旁白、主角回答和第二层语音尚未制作，缺失时使用字幕与预留时长继续。
中文显示依赖 Windows 的系统字体回退，请在展示电脑上检查中文是否正常。
完整流程画面、情绪强度、目标电脑性能与最终听感仍需人工试玩验收。

运行环境与故障排查
需要 64 位 Windows 和支持 OpenGL 3.3 的显卡驱动（Godot Compatibility）。
若无法启动，请先确认已完整解压、pck 与 exe 同目录，再检查显卡驱动。
本构建未使用代码签名。
默认日志位于 %APPDATA%\Godot\app_userdata\I See Me\logs\godot.log。
反馈时提供问题步骤和日志；无需提供任何真实心理经历。
