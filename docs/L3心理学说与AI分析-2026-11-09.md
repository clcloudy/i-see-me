# L3 心理学说介绍与 AI 分析

> 同日呈现方式更新：按用户要求，L3 正文改为固定在三维世界里的悬浮文字，沿纵深左右交错陈列，镜头逐段跟随。先前平面面板与滚动阅读的验证仅保留为历史记录。

根据用户 2026-11-09 要求实施：结合实际课堂事件，使 L3 包括心理学说介绍与依据学说的 AI 分析。沿用现有 L2 输入、DeepSeek 单次请求和第三人称抽离画面，不修改人工维护的《流程控制(veryimportant).md》编号、同步关系或插入点，不新增分支、测评分数与结局评级。此模块已接入当前课堂原型，不表示完整游戏已完成或已经通过心理干预效果验证。

## 选用依据与游戏对应

本轮选用三个互补的支撑：认知模型是理解框架，聚光灯效应是特定社会判断研究发现，自我疏离是反思视角。三者并非对玩家进行测评的量表，不要求每条表达都匹配一个学说。

| 学说 / 研究视角 | 在本游戏中怎样使用 | 不能由此得出的结论 | 来源 |
| --- | --- | --- | --- |
| Beck 认知模型 | 区分捡笔、回头、低笑、误述、不同意见、点头赞同这些可观察事件，与玩家赋予的意义；有明确填写时再联系感受 | 想法有错、负面情绪不合理，或未填写的身体反应与行动 | [Beck Institute：Understanding CBT](https://beckinstitute.org/about/understanding-cbt/) |
| 聚光灯效应 | 玩家明确写出广泛、持续或细节层面的被关注预期时，作为核对关注范围的视角；回头与画方格的事件用于介绍游戏中的不同注意方向 | 玩家必然高估关注、没人关注或没人嘲笑；仅写“有人看我”“担心说错”不够适用 | [Gilovich、Medvec 与 Savitsky（2000）原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/10707330/) |
| 自我疏离视角（self-distancing） | 为从自己身后回看、进一步观察自己如何理解事件提供设计依据；个别分析须有玩家明说的观察角度或前后理解比较 | 切换镜头即产生心理改变，玩家已经平静、更客观或获得疗效 | [Ayduk 与 Kross（2010）原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/20438226/) |

课堂联系与适用阈值是本项目的设计判断，不是这些研究验证过的游戏机制。介绍使用简短中文转述与本项目例子；不转载论文、量表、插图或治疗练习。参考来源于 2026-11-09 查阅；来源与使用方式同步登记在 `docs/素材登记.md`。

## 玩家实际看到的流程

1. L2 完成后沿用发送预览。玩家明确发送才调用在线服务，也可选择本机学说介绍与原文回看。
2. 进入 L3 后先显示三组学说介绍，每组包含定义、课堂联系、适用边界和作者/来源；正文按段落、优先按句子拆成短段，每段不超过 100 字，原文字序保持不变。各段位于固定的三维位置，左右交错并向前方纵深延伸，具有真实远近透视。可前后回看，也可随时跳过其余介绍。零选择、未填写或离线路径同样能读这些内容。
3. 在线结果逐条展示「客观事件 → 我的原话 → 采用的学说 → 引用原话的依据 → AI 暂定分析 → 尚不能确认的部分」。完整学说说明和来源可重新打开，返回后仍停在当前条目。
4. 保留贴近、部分贴近、不贴切及本机补充；不要求接受分析。无理论适用依据时明确暂不套用学说，离线时不生成替代分析。
5. 所有相关解读均被确认贴近且至少两条，才显示原有跨条目总结；否则中性收束。暂停、静音、重开和退出继续保留。

点击「看下一段」后，流程控制器平滑移动镜头到下一段；镜头到位前屏蔽段落操作，避免重复推进。文字不随相机移动，不使用正文背板或滚动面板；当前正文完整显示，前方下一段只保留较淡的标题提示，避免叠字。底部小操作区保留上一段、下一段、跳过介绍、反馈与暂停/静音/重开/退出；当前组最后一段才显示该组的反馈或结束操作。补充说明同样在世界中显示，填写框在抵达最后一段后出现在底部。

等待原有抽离转场完成后再开始移动镜头；暂停冻结移动并隐藏文字，恢复后继续。重开与完成会清空本轮文字节点、缓存及草稿，旧镜头回调不得恢复已关闭的回看。L3 地面随阅读位置重新居中，避免较长表达越过原地面的范围。

## 内容配置与生成约束

- `content/reflection.json` 的 `theories` 是唯一理论资料，包含稳定 id、名称、介绍、课堂例子、限制、适用规则、作者及来源 URL。UI 使用这份本机文案，不展示模型临时编出的理论定义或来源。
- 请求在系统消息内附上述理论资料，玩家消息仍只有原有的 `id / fact / thought / feeling`，不追加个人数据字段，不新增请求或多轮聊天。
- 每条输出为 `id / quote / theory_id / evidence / reading / uncertainty`，以及可选的跨条目 `summary`。旧的自由生成 `concept` 字段不再使用。
- `theory_id` 必须来自资料；`evidence` 是 `thought` 中连续逐字且不超过 120 字的片段。有理论必须有引文，无理论时两者同时为空。原有数量、顺序、原话、类型、长度及完成状态检查继续保留。
- 提示词要求分析解释理论、事件与引文的联系，并说明这一次联系的具体限制，不补造缺失感受、长期心理、童年经历或他人动机。
- id 白名单和原文检查只验证结构与引文来源，不能证明理论适用或分析正确；聚光灯效应和自我疏离的语义边界仍需真实模型与人工内容评审验证。
