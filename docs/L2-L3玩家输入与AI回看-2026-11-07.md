## 实际行为

- 第 11 步进入原有第三人称心流画面，保留“回到你被点到名字之前”的回溯卡；随后等待玩家操作，不自动翻页。
- 可选观察按实际发生步号排序。带点击提示的事件必须在 L1 收集过，无提示的环境事件必须实际发生过；跳过的事件不补发。
- 一次选择一个人：点击头顶事件后，镜头移近此人；到位后自动回放动作与已有声音，并填写这一条的心理感受。保留最多三件的范围，一件或零件也可完成。事实描述集中在 `content/reflection.json`，不把别人动作的原因当作已知事实。
- 每条输入一个想法，最多 600 字；感受/身体反应选填，最多 120 字。保存或跳过后停止回放，镜头返回自己身后，到位后直接恢复头顶事件选择；可直接选下一人，或点击「完成，进入下一阶段」。点已填写的事件可修改原草稿，不重复添加。空白不补默认心理答案；保留不确定、没有明显想法与跳过，按用户要求移除「只是看着」和手动重播按钮，到位后的自动循环回放仍保留。
- 独立世界面片在右侧排版，输入时不推进课堂。玩家原话的简短标记留在对应事件位置，进入 L3 清除。
- 生成前显示实际待发送内容。只有玩家点击发送才请求 DeepSeek；只传选定且明确填写的事件 id、事实、想法及可选感受。不传 L1 回答、坐标、未选观察、不确定和跳过条目。
- 只有流程控制器进入 `l3`，先完成既有抽离效果，再逐段移动镜头阅读世界中的文字。先提供认知模型、聚光灯效应、自我疏离视角三组介绍，包含课堂例子、适用限制和来源，允许跳过其余介绍。逐条回看显示原话、采用的学说名称、引自原话的依据、AI 的暂定分析与尚不确定的部分；可随时返回学说介绍，不提交反馈或推进条目。正文不再平铺于相机前的面片，底部只保留操作与必要输入框。
- 玩家可确认贴近、部分贴近或不贴切；后两者允许补充或留空继续。不再上传补充，不劝说玩家接受 AI。
- 只有至少两条 AI 解读均被确认贴近时才展示跨观察总结，否则中性收束。
- 无密钥、连接失败、响应无效或取消等待时，仍可阅读本机学说介绍并回看原文，不生成假解读；零选择也可阅读介绍后完成。
- 暂停保留草稿，结果到达也不在暂停中推进。重开/退出取消请求并清空本轮记录和标记；旧结果不能恢复已重开的体验。取消本机等待不会撤回已发送的内容。

## DeepSeek 接入

默认地址 `https://api.deepseek.com/chat/completions`，默认模型 `deepseek-flash`，非流式、关闭思考、JSON 输出。依据实施时查阅的 [Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [JSON 输出文档](https://api-docs.deepseek.com/guides/json_mode/) 配置。

2026-11-09 按用户要求，密钥改为在游戏内填写。完成 L2 后，在“选择回顾方式”页面点击“发送并生成分析”或“填写或更换密钥”，进入掩码输入框，填写后点击“使用此密钥并生成分析”。密钥仅留在当前游戏进程内存中，本次运行期间重开、重试可继续使用，退出时随客户端销毁清除。每次启动由玩家重新填写。密钥仅用于请求的 Authorization 头，玩家记录与模型提示词分别按原有数据结构发送。认证失败时可回到输入页面更换密钥。模型仍可通过 `ISEEME_AI_MODEL` 配置。

目前为开发演示直接连接，每位使用者在本次游戏中填写自己的密钥。对外分发如需共用团队额度，应另接持有密钥的服务端。

输出检查条目数量、顺序、事件 id、原话逐字对应、文本类型和长度；理论 id 须来自本机资料，引文须为玩家想法中的连续原文。拒绝截断、空白、未知理论或伪造引文。无适用依据时理论 id 和引文均为空，仅整理原话。这不是语义审核，不能保证理论选择与分析贴切；提示词限制诊断、评分、人格标签、虚构背景和断定他人意图，实际质量仍需人工评估。本轮输入和反馈不写存档或应用日志，在线数据处理仍受 DeepSeek 政策约束。
