## 二、「稍微松了口气」的来源与迁移

- 原文出处：`docs/10.22(very important)_补充六个事件.md` → 新增事件05「有人还在忙自己的事」，
  第二层感受词条写的是「稍微松了口气」、「又有一点失落」。
- `流程控制(veryimportant).md` 第 0 步只写「事件05｜有人还在忙自己的事」，没有写感受词条，
  所以从流程控制里查不到这句话——它是内容文档里的词条，不是时序。
- 按反馈：松口气发生在**主角被点到之后**（同学不用回答了，绷着的那口气松下来），
  而不是第 0 步（那时还没点名，松口气没有来由）。
  - 事件05 只保留「又有一点失落」（看见有人在忙自己的事，没有被注视的失落）。
  - 新增事件 `relief`（第 3 步，同号同步）：`SeatB07`、`SeatB05` 靠回椅背（`Pose.LEAN_BACK`），
    感受词条「稍微松了口气」「有点被留在台上」，
    想法：「老师不再扫视了，他们就松下来了」「松口气的不是我」「现在站着的只有我一个」。

## 三、开场教室：`content.ambient`

```json
"ambient": {
  "desk_top_y": 0.775,      // 教室课桌台面高度（lecture_desk_* 顶板 0.75 + 0.05/2）
  "desk_forward": 0.62,     // 桌面道具摆在座位正前方多远（座位局部 -Z 方向）
  "states": [ { "seat": "SeatB03", "pose": "WRITING", "desk": "notebook_pen" }, … ]
}
```

- 姿态只用坐姿：`SIT`（抬头听讲）、`READ`（低头看书）、`WRITING`（拿笔写字）。
- 桌面道具由 `PropKit` 程序化生成（本子 / 笔 / 铅笔 / 课本），`DialogueFlow._build_desk_props()`
  在第一次复位时生成一次，挂在 `Flow/DeskProps/Desk_<座位名>` 下；每张桌子按座位名做稳定的
  水平偏移与 ±9° 转角，满座时不至于像印刷品。
- 三个交头接耳座位对（B04/B05、C10/C11、D02/D03）不写进 `ambient`：它们由
  `_set_ambient_whispers(true)` 覆盖为交头接耳，第 3 步「忽然安静下来」再全部回到 `SIT`。

## 七、姿态过渡（2026-10-27）

**原因**：`character_pose.gd` 是纯静态姿态系统，`apply_pose()` 把目标角度一帧写进骨骼、没有任何插值，
所以每换一个姿态都是瞬切。

**修法**（未引入 AnimationPlayer，也未换成 `classmate_animated.tscn`）：

1. `character_pose.gd` 新增 `pose_transition_seconds`（默认 0.45 s，教室由内容配置给 0.5 s）。
2. `apply_pose()` 改两段式：快照当前骨骼 → 摆到目标姿态并快照目标值 → 退回起点，由 `_process`
   每帧对每根骨骼 `Quaternion.slerp`（smoothstep 缓动）逼近目标，到点 `set_process(false)`。
   快照取的是摆完之后的旋转，所以手臂 IK、掩嘴、按课本也会一起被插值。
3. 首次摆放、站立↔坐下等结构变化、或过渡时间设为 0 时仍直接到位。
4. 内容侧开关：`content/classroom_dialogue.json` 的 `"pose_transition_seconds": 0.5`，设成 `0` 即旧的瞬切。

**验证**：`_check_pose_transition()` 把 `SeatB10` 从 `SIT` 切到 `PICK_UP`，
总转角 40.5°，0.15 s 时只走了 8.8°，0.5 s 后与直接到位相差 < 2°；
`dialogue_capture.gd` 连拍的三帧（`.local/captures/pen-transition-strip.png`）能看到头慢慢低下。
