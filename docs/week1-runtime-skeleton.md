## 可运行内容

内容提示 → L1 体验者 → L2 观察者 → L3 观察观察者 → 小样结束。

进入教室后停在座位视角；玩家点击才开始下一段转场。每段默认 2.2 秒，可跳过。
转场期间继续按钮禁用并隐藏，以相同操作区域的跳过按钮替代。
跳过只把当前镜头放到目标位置，不额外推进下一层。
界面保留来源层标题，镜头完成后才显示目标层。

L1 隐藏座位上的人物；L2 移出人物头部后显露坐姿自己；L3 显露观察者。
进入 L3 转场时隐藏天花板、前墙、右墙及右侧踢脚线，并显示舞台底座。
两个人物使用相同造型与服色，教师使用不同服色，以便辨认角色。
人物显露使用与视点锚点的距离判断，避免近距离穿进头部。

Esc 和暂停按钮可在 L1、L2、L3 及转场中切换暂停，暂停菜单可继续、重开和退出。
内容提示和结束页没有进行中的表演，暂停按钮禁用；静音、重开、退出仍可用。
暂停冻结镜头及继承默认暂停模式的场景节点，UI 与流程控制器保持响应。
重开清除阶段、转场、人物可见性与舞台状态，返回内容提示；仅保留本次运行的静音偏好。
所有人物、台词与界面均为占位；无评分、个人经历输入或存档。

## 模块接口

| 模块 | 输入 / 方法 | 输出 / 信号 | 约束 |
| --- | --- | --- | --- |
| `PrototypeFlow` | `advance()`、`toggle_pause()`、`toggle_mute()`、`skip_transition()`、`restart()`、`quit()` | `stage_changed(stage_id)`；只读使用 `stage`、`transitioning`、`muted` | 唯一阶段推进者；外部不得直接改状态 |
| `PrototypeCameraRig` | `transition_to(view_id) -> bool`、`finish_transition()`、`cancel_transition()`、`snap_to(view_id)` | `transition_finished(view_id)`、`pose_changed(camera_position)` | 视角为 `l1` / `l2` / `l3`；已有转场或视角无效时返回 false |
| `PrototypeClassroom` | `set_view(view_id)`、`update_camera_position(camera_position)` | 无流程信号 | 只控制空间与人物可见性，不改剧情 |
| `PrototypeUI` | `configure(content)`、`present(stage, transitioning, paused, muted)`、`focus_primary()` | `advance_requested`、`pause_requested`、`mute_requested`、`skip_requested`、`restart_requested`、`quit_requested` | 只报告请求，暂停和静音由流程控制器切换 |

流程控制器通过主场景导出的节点引用连接三个模块，不使用 Autoload 或第三方插件。
阶段标识为 `intro`、`l1`、`l2`、`l3`、`complete`。
转场期间 `stage` 保持来源层，收到匹配目标的完成信号后才提交新阶段；
同一帧的重复推进和转场期间的推进请求会被忽略。

镜头的正常结束和跳过共享完成入口，每次转场最多通知一次。
取消不通知完成；代次标识阻止已取消的旧回调影响重开后的状态。
不要单独取消由流程发起的转场再继续游戏；游戏内应通过流程控制器重开或退出，让两个模块同时重置。

文案集中在 `content/prototype.json`：`ui` 存按钮与公共提示，`stages` 按阶段标识存 `title`、`body`。
当前没有音频映射或音源；之后由剧情、声音与主开发确认台词编号和映射，避免提前冻结正式内容结构。
静音已连接 Master 总线，后续音源应接入该总线，并置于默认可暂停的节点层级，不能放在始终处理的 UI / Flow 下。
Windows 导出时需检查 JSON 作为非场景内容文件被打包；本次没有新增导出预设或下载模板。
