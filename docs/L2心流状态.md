# L2 心流 / L3 抽离状态（L2FlowState）

> 2026-11-07：主课堂交互已改为 [L2 玩家输入 / L3 AI 回看](L2-L3玩家输入与AI回看-2026-11-07.md)。本文的材质与抽离接口仍适用；关于预写内心 OS、自动概念卡及 L3 不独立分阶段的描述为旧实现记录。改动原因是用户确认由玩家表达想法，再由 AI 提供可否认的暂定解读。

> 状态接口：`scripts/effects/l2_flow_state.gd` + `scenes/effects/l2_flow_state.tscn`
> 独立预览：`scenes/effects/l2_flow_preview.tscn`（在编辑器中按 F6 单独运行）
> 主场景接线：L2 阶段进入心流，L3 阶段进入抽离（`scenes/main.tscn`、`scripts/flow_controller.gd`）

## 做什么

同一个效果节点现在有两个阶段，可以从 L2 连续过渡到 L3。

### L2 · 心流

- 把 `target_root` 下所有 `MeshInstance3D` 的 `material_override` 换成共享的灰黑、无贴图材质；
- 以主角（`focus_node_path` 或 `activate(focus)`）为球心：
  - 半径 `focus_radius`（默认 2 m）内完全清晰；
  - 到 `focus_radius + focus_falloff`（默认 3.2 m）之间逐渐模糊；
  - 之外保持最大模糊；
- 模糊区去饱和、轻微压暗，把注意力留在清晰球内；
- 退出时把每个网格的原始 `material_override` 还回去，不修改源场景、材质资源或 `.glb`。

### L3 · 抽离

在 L2 画面上继续：

1. 只保留两类网格：名字在 `keep_floor_names` 里的节点（默认 `Floor` / `StageFloor`）和
   `protagonist_path` 指向的主角子树；
2. 把当前带模糊的 L2 画面抓成一张快照，盖在已经切到 L3 的实时画面上；
3. `isolation_seconds`（默认 1.6 s）内淡出快照，同时：
   - 其余网格隐藏；
   - 模糊半径降到 0；
   - 整体转成纯灰度；
   - 天空退成 `void_color`（默认 0.11 的中性深灰），画面只剩地板与主角；
4. 教室地板之上铺一块 **L3 专用无限地面**：纯色 + 细网格线，不接收光照/烘焙阴影，
   远处按距离淡入虚空（默认 12–30 m），因此没有原先 10 m 地板的突然截断；
5. 结束后只留下地面、主角和虚空背景；退出时恢复所有网格、原始材质、天空和模糊。

L3 地面不是把原教室地板重新打光，而是覆盖一层独立平面，所以不会带着课桌/人物的烘焙阴影。

效果不推进剧情，也不假设具体教室；由流程控制器或任意脚本决定何时进入/退出。

## 状态接口

| 方法 / 属性 | 用途 |
| --- | --- |
| `activate(focus: Node3D = null)` | 进入 L2 心流；传 `focus` 时临时指定球心，否则用 `focus_node_path` |
| `enter_l3(focus: Node3D = null)` | 从当前 L2 画面进入 L3 抽离；可同时指定球心 |
| `leave_l3(immediate = false)` | 退回 L2；默认按 `isolation_seconds` 反向过渡，`immediate=true` 立即恢复 |
| `deactivate(immediate = false)` | 退出整个效果；默认 0.6 s 淡出，`immediate=true` 立即恢复（重开/退出用） |
| `set_active(value)` / `toggle()` | 按布尔值切换 / 在进入和退出之间切换 |
| `set_focus_point(world_position)` | 用世界坐标固定球心，不跟随节点 |
| `set_focus_node(node, height = NAN)` | 改为跟随节点；可同时改相对抬高 |
| `set_focus_radius(metres)` / `set_blur_pixels(px)` | 改清晰半径 / 最大模糊 |
| `refresh_targets()` | 场景里新增网格（例如后实例化的人物）后重新收集并覆盖 |
| `set_highlight_nodes(nodes)` | 指定灰泥里要换成 `highlight_color` 的节点子树（互动角色）；激活中调用会立即重刷 |
| `is_active()` / `is_l3()` / `is_isolated()` | 是否在效果中 / 是否已进入 L3 / 抽离是否完成 |
| `get_isolation_progress()` | 0 = 完整 L2，1 = 只剩地板与主角 |
| `get_clay_mesh_count()` / `get_kept_mesh_count()` / `get_l3_floor_mesh()` | 被覆盖的网格数 / L3 保留网格数 / L3 专用地面（测试调试用） |
| `get_highlight_mesh_count()` | 被换成 `highlight_color` 的网格数（测试调试用） |
| `state_changed(active)` / `isolation_changed(isolated)` / `isolation_finished` | 状态信号 |

主要可调导出：

| 导出 | 默认 | 说明 |
| --- | --- | --- |
| `target_root_path` | `..` | 从根节点扫描网格；效果自己的 Screen 会被跳过 |
| `focus_node_path` | 空 | 相对效果的节点路径；与 `activate(focus)` 二选一 |
| `protagonist_path` | 空 | L3 保留的主角根节点；为空时只保留地板 |
| `focus_height` | 1.36 | 在节点原点之上抬高多少米 |
| `focus_radius` | 2.0 | L2 清晰球半径（米） |
| `focus_falloff` | 1.2 | 从清晰到最大模糊的过渡宽度（米） |
| `blur_pixels` | 20.0 | 720p 下的最大模糊半径；会按视口高度缩放 |
| `desaturate` | 0.15 | 模糊区去饱和强度 |
| `edge_darken` | 0.25 | 模糊区压暗强度 |
| `clay_color` | 0.27 / 0.28 / 0.30 | L2 灰黑无贴图材质的反照率 |
| `l3_clay_color` | 0.30 中性灰 | L3 保留物的灰度反照率（不带蓝/暖偏） |
| `highlight_color` | 0.21/0.14/0.09 暖棕 | 互动角色在灰泥世界里的颜色（见「互动角色换色」） |
| `void_color` | 0.11 中性灰 | L3 天空/背景的虚空色 |
| `keep_floor_names` | `Floor`、`StageFloor` | 按节点名保留地板（含子树） |
| `l3_floor_enabled` | true | 是否铺 L3 专用无限地面 |
| `l3_floor_height` | 0.0 | L3 地面的世界 Y（默认与教室地板顶面齐平） |
| `l3_floor_color` / `l3_floor_line_color` | 0.42/0.44/0.46、0.22/0.23/0.24 | 地面纯色 / 细线颜色 |
| `l3_floor_tile` / `l3_floor_line_width` | 3.0 m / 0.8 px | 网格尺寸 / 线宽 |
| `l3_floor_fade_start` / `l3_floor_fade_end` | 12 m / 30 m | 地面开始/完全淡入虚空的相机距离 |
| `isolation_seconds` | 1.6 | L2 → L3 的渐变时长 |
| `transition_seconds` | 0.6 | 整个效果淡入/淡出时长；测试可设 0 |
| `auto_activate` | false | 进入场景就激活 L2，预览场景用 |

### 调用示例

```gdscript
@export var flow_state: L2FlowState

func enter_l2(protagonist: Node3D) -> void:
    # 主角根节点在地面，ViewAnchor 在头部高度
    flow_state.activate(protagonist.get_node("ViewAnchor"))

func enter_l3() -> void:
    flow_state.enter_l3()

func leave_all() -> void:
    flow_state.deactivate()
```

L3 保留哪名主角由 `protagonist_path` 决定，例如预览场景里的 `../Protagonist`。
如果主角节点还没有头部锚点，也可以先设 `focus_height = 1.36` 再 `activate(protagonist)`。

## 主场景接线

`scenes/main.tscn` 中有一个 `L2FlowState` 实例：

- `target_root_path = ..`（主场景根）
- `focus_node_path = ../Classroom/CameraAnchors/PlayerSeatSpot`
- `focus_height = 1.36`（座位原点 → 头部）
- `protagonist_path` 暂为空：主场景目前还没有人物，所以 L3 只保留地板；接入主角后指向它的根节点即可

`scripts/flow_controller.gd`：

- 进入 `l2` 时 `flow_state.activate()`；
- 进入 `l3` 时 `flow_state.enter_l3()`；
- 进入 `l1` / `intro` / `complete` 时 `deactivate()`；
- `restart()` / `quit()` 用 `deactivate(true)`，避免重开或退出时还停在抽离画面；
- L2 → L3 的镜头转场结束后才调用 `enter_l3()`，让快照与 L3 机位对齐。

## 课堂对话接线

`scenes/classroom_dialogue.tscn` 里的 `L2FlowState`：

- `protagonist_path = ../Seating/ProtagonistSit`（L3 只保留这名坐姿主角）；
- `focus_node_path = ../Seating/ProtagonistSit/ViewAnchor`，L2 的清晰球同样以他为中心。

`scripts/dialogue_flow.gd`：

- L2 的词条卡分三组：**我看到的（只回放收集过的观察）** → 思绪倒放 → 对观察的观察；
  每组每一条都带世界坐标，落在教室里对应的位置（见下一节「第二层词条的三维呈现」）；
- 第一张「对观察的观察」卡开始时调用一次 `flow_state.enter_l3()`，之后 5 张观察卡都在
  「只剩地板与主角、纯灰度、无模糊」的画面上浮现；
- `complete` 时 `deactivate()` 恢复教室（同时 `thought_cleared` 收掉最后一块思绪牌）；
  重开时 `deactivate(true)` 并清空 `_l3_entered`。

这样真实课堂流程不需要单独增加 `l3` 阶段名，就能在「抽离与对观察的观察」环节用上 L3 画面。

## L1 收集 → L2 内心 OS（2026-11-01）

第一层里 8 个可点击的观察提示（见 `docs/互动小球与回答框要求-2026-10-31.md`）点开即收集；
第二层的「我看到的」只回放**收集到的那些**，没点开的观察不会变成回想。

- 收集登记：`SceneUI3D` 把 `EventOrb3D.collected` 转成 `DialogueFlow.note_observation_collected(event_id)`，
  记进 `_collected`（按事件 id 去重），并发 `observation_collected(event_id, label)`。
  重开（`_reset_world`）清空。
- **看得见的收集（2026-11-01 补）**：登记成功后，界面在屏幕右下角放一条小卡
  （`DialogueUI.collect_observation`，世界面片 `WorldCollected`，overlay 不参与遮挡），
  同时观察提示朝那个位置飞过去再消失（`EventOrb3D.collect_into`）。
  第二层每条「我看到的」卡片播放时，`DialogueFlow._present_l2_card` 调
  `DialogueUI.expand_collected(event_id)`：把对应那条从口袋抽走，返回它的世界坐标，
  思绪牌从这个起点飞到事件发生的位置（`L2Thought3D.appear_from`）。
  口袋空了自动收起；重开 / 通关清空。收集夹只是反馈，判定仍然只看 `_collected`。
- 卡片的取舍（`_l2_observation_entries()`）：
  - 有提示的观察（`orb != false`）：必须被收集过才进第二层；
  - 环境事件（`quiet` / `class_moves_on`，`orb: false`）：没有提示可点，属于自己在那几秒里的状态，照旧保留；
  - 顺序仍按流程步号（同一步按实际触发顺序），与「回溯到第 0 步」的说法一致。
- 卡片内容：标题 = `l2.os_title`（默认「我看到的」）+ ` · ` + 事件 `label`；正文取事件的 `os`
  （可选，写回看时的说法），缺省回落到 `thoughts`（事件当下写好的想法）。两者都支持
  单条字符串或字符串数组；`os_voice` 可选，登记进配音清单，缺录音时按预留时长走。
- 环境事件不加前缀，标题就是事件名（例如「忽然安静下来」）——它不是"我看到别人"。
- 收集与否**不写进任何判定**：不分好坏、不加分、不影响第 9–11 步、不改变老师语气与后续事件。
  唯一的差别就是第二层回放哪几段。
- 进第二层时 `SceneUI3D` 会清掉还没点开的提示：提示是 Sprite3D/Label3D，不跟着 L2 的
  材质覆盖变灰，留在灰化的教室里会很扎眼；收集窗口本来也只在第一层。

**点击能生效的前提**：观察提示靠 `Area3D` 的鼠标事件收起，而视口默认不做三维拾取
（`Viewport.physics_object_picking = false`）。`SceneUI3D._enable_picking()` 打开它，
并设 `physics_object_picking_first_only = true`，两个提示叠在一起时只收起最近的那个。
这一项以前漏了，表现是"小球看得见、点不动"。

## 第二层词条的三维呈现（2026-11-01）

第二层的词条**不再平铺在相机前的一块面片上**（以前是 `DialogueUI` 的 `CardPanel`，钉在玩家面前 1.16 m、
永远占屏幕中央）。现在每一条都带一个世界坐标，长在它对应的地方。

- 节点：`scripts/l2_thought_3d.gd`（`L2Thought3D`）。`SceneUI3D` 收到
  `DialogueFlow.thought_presented(title, body, anchor, kind, origin)` 后生成一块，`thought_cleared` 收掉；
  同一时刻只有一块，换下一条时旧的 0.16 s 退场（两条字叠着会糊成一团）。
  `origin` 是飞入起点（从收集夹抽出来的那一条），`Vector3.INF` 表示没有起点、直接淡入。
- 长什么样：锚点一个亮点 + 一条细引线 + 一块朝相机的文字牌（`BILLBOARD_FIXED_Y`，字始终是立的）。
  `kind` 只决定配色：`seen` 青 / `rewind` 暖黄 / `replay` 灰绿 / `concept` 米金。
  亮点 + 引线是"这条思绪挂在这儿"的唯一线索，不能省。
- 落点（`_build_l2_cards()` 写进每条的 `position`）：

  | 词条 | 默认落点 | 内容里可覆盖 |
  | --- | --- | --- |
  | 回溯（回到最开始） | 自己课桌上方 `_seat + (0, 1.15, -0.50)` | `l2.rewind_position` |
  | 我看到的（观察） | 事件发生处：`events.<id>.orb_position` | `events.<id>.thought_position`（环境事件的默认来源） |
  | 思绪倒放 | 从自己课桌往讲台的过道，逐条前进 0.72 m、抬高 0.10 m | `l2.replay[i].position` |
  | 对观察的观察 | 抽离后围着主角头部的半圆（半径 1.15 m、张角 150°、高度 −0.25 m） | `l2.observations[i].position` 或 `l2.observation_radius` / `observation_span_degrees` / `observation_height` |

  抽离后的高度取负值是有意的：牌面本身还要往上抬一截，落点低一点，牌才落在胸口到头部这一带。
- 尺寸与可读性：
  - 屏幕占比恒定（`screen_fraction` = 0.26），不按世界尺寸缩放——远处的事件不能小到读不出来
    （与世界字幕同一条「可读优先」原则）；
  - 牌面要顶出画外时，沿相机的上/右方向平移回来（四周 20 px，顶端另留 122 px 避开控制条）；
    **只平移、不缩小**，所以"它挂在那儿"的关系还在；
  - 高度按排版后的真实内容高度贴紧（`_fit_to_content`）：正文换行数只有排版完才知道，
    用估算公式会把最后一行裁掉（第一版就踩了这个坑）。
- 绘制顺序：文字牌 `render_priority` 6、锚点/引线材质 5，都排在 L2 后处理四边形（2）之后——
  否则 20 px 的亮点会被模糊糊掉（看起来像根本没画），文字也会被一起灰化；顶部控制条是 8，压在牌之上。
- 分组：整棵子树进 `dialogue_fx`（`TRANSIENT_FX_GROUP`），所以既不会被灰泥材质替换，也不会在 L3 被隐藏。
- 兼容：没有接 `SceneUI3D` 的场景（`thought_presented` 没有监听者）自动退回旧的相机前面片
  `interface.show_card()`，第二层不会变成空白。
- 验证：`tests/dialogue_check.gd` 的 `_check_l2_thoughts`（场上只有一块、落点都在教室里、
  收集到的观察落在它的 `orb_position`、概念卡围着主角、不进灰泥清单、投影在画幅内）；
  截图 `.local/captures/dialogue-06-l2-rewind.png`、`dialogue-07-l2-seen-1.png`、
  `dialogue-08-l2-seen-2.png`、`dialogue-09-l3-concepts.png`。
  牌的浓淡、远近与可读性仍需人实际看（自动截图只证明它落在该落的地方）。

## 第二层的镜头：逐条正对正在说的那一条（2026-11-01）

以前第二层的机位固定在 `camera.l2_position` 一直看着坐着的自己：词条虽然长在各自的座位上，
但播放时它可能落在画面边角，甚至要靠 `_shift_into_frame` 从边缘推回来——读的时候镜头没在"看它"。

现在**每条内容开始播时，镜头转向它的锚点**：

- `DialogueFlow._present_l2_card()` 先调 `_aim_l2_camera(anchor)`，再发 `thought_presented`：
  牌一出现就已经在画面中央，不再有"先在边角露一下再被推回来"的过程。
- 注视点 = 锚点 + `camera.l2_aim_lift`（默认 0.5 m）。牌面挂在亮点之上、细线连着两者，
  视线落在锚点上方时亮点在下、牌在中央偏上，两者都看得见；抬 0.5 m 时牌心基本正对镜头，
  文字不会被俯看成梯形。
- **只转不走近**：机位仍停在 `l2_position`，看得出内容确实长在那个座位、那张桌子那边，
  而不是浮在屏幕前。
- 转视线用单独的慢速（`camera.l2_look_smoothing`，默认 2.6；第一人称仍是 `look_smoothing` 6.0）：
  两条内容之间隔 2~3 s，够它慢慢看过去，不是甩头换焦点。由 `camera.set_slow_look()` 切换，
  复位时关掉。
- 第二层不再有自由转头（`_enter_l2()` 里 `set_free_look(false)`）：玩家的朝向会和"正对"打架。
- 验证：`tests/dialogue_check.gd` 的 `_check_l2_thoughts` 断言注视点落在当前这块牌的锚点上方
  0.5 m 内、且牌心投影在画面中央一带；截图 `dialogue-06-l2-rewind.png`、
  `dialogue-08-l2-seen-2.png`、`dialogue-09-l3-concepts.png` 已人工看过构图。

## 互动角色换色（2026-11-01）

灰泥世界里不是所有人都一样灰：这一节课里**对我做出反应的人**换成 `highlight_color` 的暖棕，
一眼能看出谁在回头、谁在低笑、谁还在低头。

- 谁算：`DialogueFlow._l2_highlight_nodes()` 取事件的演员表
  （`events.<id>.poses[].actor` / `clips[].actor` → `actors` 映射 → `Seating/<座位>`），
  只收**带观察提示**的事件；环境事件（`quiet` / `class_moves_on`）不算「谁在回应我」，不参与换色。
  同一个座位只收一次。
- 口径 `content/classroom_dialogue.json` 的 `l2.highlight_actors`：
  - `"observed"`（默认）：发生过、带提示的观察，不管玩家有没有点开；
  - `"collected"`：只标玩家点开收集过的（与第二层「我看到的」同一套口径）；
  - `"off"`：全班灰泥，回到原来的单一灰。
- 怎么上：`L2FlowState.set_highlight_nodes(座位节点数组)`，被点名节点的**整棵子树**改用
  `_accent_material`（同粗糙度、只换颜色），与灰泥共用一套保存/恢复；抽离时暖色也一起退成中性灰，
  L3 画面里不留彩色（何况那些人在 L3 本来就会被隐藏）。
- 颜色：`highlight_color` = 0.21/0.14/0.09。比灰泥**暗**、比灰泥**暖**，所以在强光 + 泛光下
  不会发光过曝。试过 0.62/0.45/0.28 与 0.40/0.25/0.14，都亮成橙色光斑；0.30/0.20/0.13 仍偏橙。
- 主角不换色：他是被看的那个人，不是"做出反应的人"。
- 验证：`tests/dialogue_check.gd` 的 `_check_l2_state` 断言有人被换色、`quiet` 的演员仍是灰、
  换色网格数 < 灰泥总数、`collected` 口径下换色人数减少；截图 `.local/captures/dialogue-06b-l2-highlight.png`。
  颜色观感仍需人实际看（不同显示器/亮度下暖棕的浓淡会变）。

## 实现与兼容性

- 项目使用 **Compatibility** 渲染器。此渲染器的 `depth_texture` 是反向 Z，着色器用 `near / depth` 近似视空间距离，再乘屏幕射线得到像素的视空间位置；若以后切到 Forward+，这里需要重新校准。
- L2 的后处理是一个挂在相机前的 **透明全屏 Quad**（`Screen`，视距 1 m），使用 `hint_screen_texture` + `hint_depth_texture`；不依赖 Forward+ 的 CompositorEffect。界面不是屏幕平铺，而是相机前的世界空间面片（`DialogueUI` 的 `Sprite3D`），靠更高的 `render_priority` 排在后处理之后，因此不被模糊/灰化（顺序见下一条）。
- 灰黑无贴图不是屏幕滤镜，而是对 `MeshInstance3D.material_override` 的临时替换；因此会真正去掉木头、墙面、衣服等贴图。只保存/恢复 `material_override`，不改网格表面材质或源资源。
- L3 的“只留地板与主角”用 **独立 SubViewport 快照**，不是把其余物体做成半透明：
  - L3 开始时，额外的 SubViewport 用一台与主相机同步的相机渲染一张完整的 L2 画面（包含屏幕后处理，不含 UI）；
  - 主场景立刻隐藏其余网格，只留地板与主角；
  - 快照作为 `TextureRect` 盖在 3D 之上、UI 之下，按 `isolation_seconds` 淡出；
  - 因此过渡期间不会出现透明排序、黑色残影或逐物件消散的噪点，地板与主角始终稳定。
  - 这个做法假设 L3 抽离期间相机基本静止；如果以后 L3 里还要大幅移动相机，需要改为每帧重抓或双相机方案。
- 天空在 L3 通过屏幕着色器按深度换成 `void_color`；L3 地面是独立 unshaded 平面 + `shaders/l3_floor.gdshader`，
  按世界坐标画网格并按相机距离淡入虚空；它不接收光照/烘焙阴影，也不会出现原教室地板的 10 m 边缘。
  纯灰度仍是屏幕着色器对整幅画面做亮度混合。
- 默认 24 次采样、20 px 模糊；L3 时模糊降到 0，着色器会跳过多余的采样循环。未在目标展示机上测帧率；若低端机卡顿，先降 `blur_pixels` 或采样数（着色器里的 `TAPS`）。
- **绘制顺序**：后处理四边形的材质 `render_priority` 必须**低于**三维 UI（现为 2；世界面板面片 4、
  顶部控制条 8、世界字幕 10、第二层思绪牌 6 与其锚点材质 5）。它不测深度、先前设成 127，
  会把整个第二层的词条整块盖住——截图里只剩灰化教室、卡片全黑。
  `tests/dialogue_check.gd` 的 `_check_l2_state` 现在守着这条。
