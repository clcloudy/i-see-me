# L2 心流 / L3 抽离状态（L2FlowState）

> 状态接口：`scripts/effects/l2_flow_state.gd` + `scenes/effects/l2_flow_state.tscn`
> 独立预览：`scenes/effects/l2_flow_preview.tscn`（在编辑器中按 F6 单独运行）
> 主场景接线：L2 阶段进入心流，L3 阶段进入抽离（`scenes/main.tscn`、`scripts/flow_controller.gd`）

## 做什么

同一个效果节点现在有两个阶段，可以从 L2 连续过渡到 L3。

### L2 · 心流

- 把 `target_root` 下所有 `MeshInstance3D` 的 `material_override` 换成共享的灰黑、无贴图材质；
- 以主角（`focus_node_path` 或 `activate(focus)`）为球心：
  - 半径 `focus_radius`（默认 2 m）内完全清晰；
  - 到 `focus_radius + focus_falloff`（默认 3.2 m）之间逐渐模糊；
  - 之外保持最大模糊；
- 模糊区去饱和、轻微压暗，把注意力留在清晰球内；
- 退出时把每个网格的原始 `material_override` 还回去，不修改源场景、材质资源或 `.glb`。

### L3 · 抽离

在 L2 画面上继续：

1. 只保留两类网格：名字在 `keep_floor_names` 里的节点（默认 `Floor` / `StageFloor`）和
   `protagonist_path` 指向的主角子树；
2. 把当前带模糊的 L2 画面抓成一张快照，盖在已经切到 L3 的实时画面上；
3. `isolation_seconds`（默认 1.6 s）内淡出快照，同时：
   - 其余网格隐藏；
   - 模糊半径降到 0；
   - 整体转成纯灰度；
   - 天空退成 `void_color`（默认 0.11 的中性深灰），画面只剩地板与主角；
4. 教室地板之上铺一块 **L3 专用无限地面**：纯色 + 细网格线，不接收光照/烘焙阴影，
   远处按距离淡入虚空（默认 12–30 m），因此没有原先 10 m 地板的突然截断；
5. 结束后只留下地面、主角和虚空背景；退出时恢复所有网格、原始材质、天空和模糊。

L3 地面不是把原教室地板重新打光，而是覆盖一层独立平面，所以不会带着课桌/人物的烘焙阴影。

效果不推进剧情，也不假设具体教室；由流程控制器或任意脚本决定何时进入/退出。

## 状态接口

| 方法 / 属性 | 用途 |
| --- | --- |
| `activate(focus: Node3D = null)` | 进入 L2 心流；传 `focus` 时临时指定球心，否则用 `focus_node_path` |
| `enter_l3(focus: Node3D = null)` | 从当前 L2 画面进入 L3 抽离；可同时指定球心 |
| `leave_l3(immediate = false)` | 退回 L2；默认按 `isolation_seconds` 反向过渡，`immediate=true` 立即恢复 |
| `deactivate(immediate = false)` | 退出整个效果；默认 0.6 s 淡出，`immediate=true` 立即恢复（重开/退出用） |
| `set_active(value)` / `toggle()` | 按布尔值切换 / 在进入和退出之间切换 |
| `set_focus_point(world_position)` | 用世界坐标固定球心，不跟随节点 |
| `set_focus_node(node, height = NAN)` | 改为跟随节点；可同时改相对抬高 |
| `set_focus_radius(metres)` / `set_blur_pixels(px)` | 改清晰半径 / 最大模糊 |
| `refresh_targets()` | 场景里新增网格（例如后实例化的人物）后重新收集并覆盖 |
| `is_active()` / `is_l3()` / `is_isolated()` | 是否在效果中 / 是否已进入 L3 / 抽离是否完成 |
| `get_isolation_progress()` | 0 = 完整 L2，1 = 只剩地板与主角 |
| `get_clay_mesh_count()` / `get_kept_mesh_count()` / `get_l3_floor_mesh()` | 被覆盖的网格数 / L3 保留网格数 / L3 专用地面（测试调试用） |
| `state_changed(active)` / `isolation_changed(isolated)` / `isolation_finished` | 状态信号 |

主要可调导出：

| 导出 | 默认 | 说明 |
| --- | --- | --- |
| `target_root_path` | `..` | 从根节点扫描网格；效果自己的 Screen 会被跳过 |
| `focus_node_path` | 空 | 相对效果的节点路径；与 `activate(focus)` 二选一 |
| `protagonist_path` | 空 | L3 保留的主角根节点；为空时只保留地板 |
| `focus_height` | 1.36 | 在节点原点之上抬高多少米 |
| `focus_radius` | 2.0 | L2 清晰球半径（米） |
| `focus_falloff` | 1.2 | 从清晰到最大模糊的过渡宽度（米） |
| `blur_pixels` | 20.0 | 720p 下的最大模糊半径；会按视口高度缩放 |
| `desaturate` | 0.15 | 模糊区去饱和强度 |
| `edge_darken` | 0.25 | 模糊区压暗强度 |
| `clay_color` | 0.27 / 0.28 / 0.30 | L2 灰黑无贴图材质的反照率 |
| `l3_clay_color` | 0.30 中性灰 | L3 保留物的灰度反照率（不带蓝/暖偏） |
| `void_color` | 0.11 中性灰 | L3 天空/背景的虚空色 |
| `keep_floor_names` | `Floor`、`StageFloor` | 按节点名保留地板（含子树） |
| `l3_floor_enabled` | true | 是否铺 L3 专用无限地面 |
| `l3_floor_height` | 0.0 | L3 地面的世界 Y（默认与教室地板顶面齐平） |
| `l3_floor_color` / `l3_floor_line_color` | 0.42/0.44/0.46、0.22/0.23/0.24 | 地面纯色 / 细线颜色 |
| `l3_floor_tile` / `l3_floor_line_width` | 3.0 m / 0.8 px | 网格尺寸 / 线宽 |
| `l3_floor_fade_start` / `l3_floor_fade_end` | 12 m / 30 m | 地面开始/完全淡入虚空的相机距离 |
| `isolation_seconds` | 1.6 | L2 → L3 的渐变时长 |
| `transition_seconds` | 0.6 | 整个效果淡入/淡出时长；测试可设 0 |
| `auto_activate` | false | 进入场景就激活 L2，预览场景用 |

### 调用示例

```gdscript
@export var flow_state: L2FlowState

func enter_l2(protagonist: Node3D) -> void:
    # 主角根节点在地面，ViewAnchor 在头部高度
    flow_state.activate(protagonist.get_node("ViewAnchor"))

func enter_l3() -> void:
    flow_state.enter_l3()

func leave_all() -> void:
    flow_state.deactivate()
```

L3 保留哪名主角由 `protagonist_path` 决定，例如预览场景里的 `../Protagonist`。
如果主角节点还没有头部锚点，也可以先设 `focus_height = 1.36` 再 `activate(protagonist)`。

## 主场景接线

`scenes/main.tscn` 中有一个 `L2FlowState` 实例：

- `target_root_path = ..`（主场景根）
- `focus_node_path = ../Classroom/CameraAnchors/PlayerSeatSpot`
- `focus_height = 1.36`（座位原点 → 头部）
- `protagonist_path` 暂为空：主场景目前还没有人物，所以 L3 只保留地板；接入主角后指向它的根节点即可

`scripts/flow_controller.gd`：

- 进入 `l2` 时 `flow_state.activate()`；
- 进入 `l3` 时 `flow_state.enter_l3()`；
- 进入 `l1` / `intro` / `complete` 时 `deactivate()`；
- `restart()` / `quit()` 用 `deactivate(true)`，避免重开或退出时还停在抽离画面；
- L2 → L3 的镜头转场结束后才调用 `enter_l3()`，让快照与 L3 机位对齐。

## 课堂对话接线

`scenes/classroom_dialogue.tscn` 里的 `L2FlowState`：

- `protagonist_path = ../Seating/ProtagonistSit`（L3 只保留这名坐姿主角）；
- `focus_node_path = ../Seating/ProtagonistSit/ViewAnchor`，L2 的清晰球同样以他为中心。

`scripts/dialogue_flow.gd`：

- L2 的词条卡分三组：事件想法 → 思绪倒放 → 对观察的观察；
- 第一张「对观察的观察」卡开始时调用一次 `flow_state.enter_l3()`，之后 5 张观察卡都在
  「只剩地板与主角、纯灰度、无模糊」的画面上浮现；
- `complete` 时 `deactivate()` 恢复教室；重开时 `deactivate(true)` 并清空 `_l3_entered`。

这样真实课堂流程不需要单独增加 `l3` 阶段名，就能在「抽离与对观察的观察」环节用上 L3 画面。

## 实现与兼容性

- 项目使用 **Compatibility** 渲染器。此渲染器的 `depth_texture` 是反向 Z，着色器用 `near / depth` 近似视空间距离，再乘屏幕射线得到像素的视空间位置；若以后切到 Forward+，这里需要重新校准。
- L2 的后处理是一个挂在相机前的 **透明全屏 Quad**（`Screen`，视距 1 m），使用 `hint_screen_texture` + `hint_depth_texture`；不依赖 Forward+ 的 CompositorEffect。UI（CanvasLayer）在 3D 之后绘制，所以不被模糊/灰化。
- 灰黑无贴图不是屏幕滤镜，而是对 `MeshInstance3D.material_override` 的临时替换；因此会真正去掉木头、墙面、衣服等贴图。只保存/恢复 `material_override`，不改网格表面材质或源资源。
- L3 的“只留地板与主角”用 **独立 SubViewport 快照**，不是把其余物体做成半透明：
  - L3 开始时，额外的 SubViewport 用一台与主相机同步的相机渲染一张完整的 L2 画面（包含屏幕后处理，不含 UI）；
  - 主场景立刻隐藏其余网格，只留地板与主角；
  - 快照作为 `TextureRect` 盖在 3D 之上、UI 之下，按 `isolation_seconds` 淡出；
  - 因此过渡期间不会出现透明排序、黑色残影或逐物件消散的噪点，地板与主角始终稳定。
  - 这个做法假设 L3 抽离期间相机基本静止；如果以后 L3 里还要大幅移动相机，需要改为每帧重抓或双相机方案。
- 天空在 L3 通过屏幕着色器按深度换成 `void_color`；L3 地面是独立 unshaded 平面 + `shaders/l3_floor.gdshader`，
  按世界坐标画网格并按相机距离淡入虚空；它不接收光照/烘焙阴影，也不会出现原教室地板的 10 m 边缘。
  纯灰度仍是屏幕着色器对整幅画面做亮度混合。
- 默认 24 次采样、20 px 模糊；L3 时模糊降到 0，着色器会跳过多余的采样循环。未在目标展示机上测帧率；若低端机卡顿，先降 `blur_pixels` 或采样数（着色器里的 `TAPS`）。

## 当前边界 / 未完成

- **主场景目前仍没有主角**，因此主场景 L3 截图只显示地板与虚空，不是目标构图；目标构图在预览场景。接入主角时：
  1. 把主角放进主场景（例如 `Classroom/SeatedSelf` 或独立 `Protagonist`）；
  2. 把 `L2FlowState.protagonist_path` 指向主角根节点；
  3. 由主开发确认共享镜头/主场景变更后再提交。
- 教室地板仍保留在场景里（供流程/测试判断），但 L3 时被专用地面盖住；如果设 `l3_floor_enabled = false`，
  才会重新看到原教室地板的烘焙阴影和 10 m 边缘。要停用烘焙阴影也可以给保留物件临时关 `gi_mode`，
  但那会连带影响主角以外物件的观感，本次没有默认这么做。
- **主角到老师的清晰走廊**没有做（用户明确可以先不做）。
- 文案仍是“L2 · 观察者 / 从座位旁看过去……”与 L3 的观察观察者语义，需要剧情负责人更新 `content/prototype.json`。
- 自动截图只验证了不黑屏、尺寸、界面边界、基本对比度和阶段切换；灰黑层次、模糊强度、过渡节奏、眩晕/舒适度需要人实际观看和试玩。
- 新课堂对话流程（`scripts/dialogue_flow.gd`）的 `l2` 阶段在「对观察的观察」卡片开始时进入 L3 画面，
  但没有拆出独立的 `l3` 阶段名；如果以后需要按阶段做暂停/跳过/日志区分，再拆阶段。
- 对话场景的 L3 沿用 L2 的第三人称机位，不做额外拉远；原型 `main.tscn` 的 L3 仍是独立机位。
