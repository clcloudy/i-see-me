# L2 心流状态（L2FlowState）

> 状态接口：`scripts/effects/l2_flow_state.gd` + `scenes/effects/l2_flow_state.tscn`
> 独立预览：`scenes/effects/l2_flow_preview.tscn`（在编辑器中按 F6 单独运行）
> 主场景接线：L2 阶段自动进入，其他阶段退出（`scenes/main.tscn`、`scripts/flow_controller.gd`）

## 做什么

激活时：

- 把 `target_root` 下所有 `MeshInstance3D` 的 `material_override` 换成共享的灰黑、无贴图材质；
- 以主角（`focus_node_path` 或 `activate(focus)`）为球心：
  - 半径 `focus_radius`（默认 2 m）内完全清晰；
  - 到 `focus_radius + focus_falloff`（默认 3.2 m）之间逐渐模糊；
  - 之外保持最大模糊；
- 模糊区去饱和、轻微压暗，把注意力留在清晰球内；
- 退出时把每个网格的原始 `material_override` 还回去，不修改源场景、材质资源或 `.glb`。

效果不推进剧情，也不假设具体教室；由流程控制器或任意脚本决定何时进入/退出。

## 状态接口

| 方法 / 属性 | 用途 |
| --- | --- |
| `activate(focus: Node3D = null)` | 进入心流状态；传 `focus` 时临时指定球心，否则用 `focus_node_path` |
| `deactivate(immediate = false)` | 退出；默认 0.6 s 淡出，`immediate=true` 立即恢复（重开/退出用） |
| `set_active(value)` / `toggle()` | 按布尔值切换 / 在进入和退出之间切换 |
| `set_focus_point(world_position)` | 用世界坐标固定球心，不跟随节点 |
| `set_focus_node(node, height = NAN)` | 改为跟随节点；可同时改相对抬高 |
| `set_focus_radius(metres)` | 改清晰半径；默认 2.0 |
| `refresh_targets()` | 场景里新增网格（例如后实例化的人物）后重新收集并覆盖 |
| `is_active()` / `state_changed(active)` | 状态查询 / 信号 |
| `get_clay_mesh_count()` | 当前被覆盖的网格数，测试或调试用 |

主要可调导出：

| 导出 | 默认 | 说明 |
| --- | --- | --- |
| `target_root_path` | `..` | 从根节点扫描网格；效果自己的 Screen 会被跳过 |
| `focus_node_path` | 空 | 相对效果的节点路径；与 `activate(focus)` 二选一 |
| `focus_height` | 1.36 | 在节点原点之上抬高多少米；若节点本身就是头部锚点，设 0 |
| `focus_radius` | 2.0 | 清晰球半径（米） |
| `focus_falloff` | 1.2 | 从清晰到最大模糊的过渡宽度（米） |
| `blur_pixels` | 20.0 | 720p 下的最大模糊半径；会按视口高度缩放 |
| `desaturate` | 0.15 | 模糊区去饱和强度 |
| `edge_darken` | 0.25 | 模糊区压暗强度 |
| `clay_color` | 0.27 / 0.28 / 0.30 | 灰黑无贴图材质的反照率 |
| `transition_seconds` | 0.6 | 淡入/淡出时间；测试可设 0 |
| `auto_activate` | false | 进入场景就激活，预览场景用 |

### 调用示例

```gdscript
@export var flow_state: L2FlowState

func enter_l2(protagonist: Node3D) -> void:
    # 主角根节点在地面，ViewAnchor 在头部高度
    flow_state.activate(protagonist.get_node("ViewAnchor"))

func leave_l2() -> void:
    flow_state.deactivate()
```

如果主角节点还没有头部锚点，也可以：

```gdscript
flow_state.focus_height = 1.36
flow_state.activate(protagonist)
```

## 实现与兼容性

- 项目使用 **Compatibility** 渲染器。此渲染器的 `depth_texture` 是反向 Z，着色器用 `near / depth` 近似视空间距离，再乘屏幕射线得到像素的视空间位置；与 `focus_view` 比较即可得到米制距离。若以后切到 Forward+，这里需要重新校准。
- 后处理是一个挂在相机前的 **透明全屏 Quad**（`Screen`，视距 1 m），使用 `hint_screen_texture` + `hint_depth_texture`；不依赖 Forward+ 的 CompositorEffect。UI（CanvasLayer）在 3D 之后绘制，所以不被模糊/灰化。
- 灰黑无贴图不是屏幕滤镜，而是对 `MeshInstance3D.material_override` 的临时替换；因此会真正去掉木头、墙面、衣服等贴图。只保存/恢复 `material_override`，不改网格表面材质或源资源。
- 效果自己的 Screen 在 `target_root` 子树内，扫描时会跳过，不会被自己的 clay 材质覆盖。
- 默认 24 次采样、20 px 模糊；未在目标展示机上测帧率。若低端机卡顿，先降 `blur_pixels` 或采样数（着色器里的 `TAPS`）。

## 当前边界 / 未完成

- **主场景 L2 仍是旧观察者机位，静态教室也还没有人物**。因此主场景 L2 截图只是“状态已接入”的验证，不是目标构图；目标构图在预览场景。要接进主场景，需要：
  1. 把 `camera_rig.tscn` 的 L2 机位改到头部后方（可直接参考预览的相机与注视点）；
  2. 把主角放进主场景（例如 `Classroom/SeatedSelf` 或独立 `Protagonist`），并把 `focus_node_path` 指向它的 `ViewAnchor`、`focus_height` 改 0；
  3. 由主开发确认共享镜头/主场景变更后，再提交。
  本次没有擅自改共享镜头或往静态教室塞人物。
- **主角到老师的清晰走廊**没有做（用户明确可以先不做）。将来可以在着色器里再加一条“视线胶囊”遮罩，或在 2 m 球之外维护第二个焦点。
- 文案仍是“L2 · 观察者 / 从座位旁看过去……”，与新 L2 的心流语义不一致，需要剧情负责人更新 `content/prototype.json`。
- 自动截图只验证了不黑屏、尺寸、界面边界和基本对比度；灰黑层次、模糊强度、眩晕/舒适度需要人实际观看和试玩。
