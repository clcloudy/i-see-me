# 配音接口与录音清单（2026-10-25）

流程侧已经把每一句台词、每一条音效拆成**清单 id**，录好的文件按名字放进目录即可自动生效，
不需要改脚本。时序见 [流程控制实现](流程控制实现-2026-10-25.md)。

## 一、放哪里、怎么命名

| 类型 | 目录 | 清单 | 命名 |
| --- | --- | --- | --- |
| 台词（老师 / 我 / 同学 / 旁白） | `assets/audio/voice/` | `content/classroom_dialogue.json` → `voice.cues` | 见下表「文件」列，全小写下划线 |
| 音效 / 环境 | `assets/audio/sfx/` | 同上 → `sfx.cues` | 见下表 |
| 全场课堂底噪（循环） | `assets/audio/sfx/murmur_loop.wav` | `sfx.cues.murmur_loop` | 进入教室第 0 步起播，进入第二层转场停止；循环由运行时设置，无需改导入选项 |

- 格式：清单按实际文件填写 `.ogg`（Vorbis）或 `.wav`（PCM），均可由 Godot 直接导入；2026-11-04 这批用户提供素材保留为单声道 48 kHz / 16-bit WAV。台词建议单声道 44.1/48 kHz，峰值 −3 dB，句首留 0.15s、句尾留 0.2s 静音，方便卡点。
- 文件名必须与「文件」列一致；改了名字就要同步改 `voice.cues` 里对应的值。
- 没有文件时流程**不会报错**：按 JSON 预留秒数继续，字幕照常；只是没有声音。
  清单里写了但配置没引用的 id（孤儿）会被无头检查报出来；引用了却没登记的 id 会打一次警告。
- 文件缺失清单：跑 `tests/dialogue_check.gd`，最后一行会打印
  `VOICE: 31 cues registered, N recorded (...)`，`recorded` 里就是已经就位的条目。

## 二、时长怎么定

每个节拍时长 = `max(JSON 预留, 字幕结束, 音频长度 + 0.25s)`。**录得比预留长不会截断**，流程会等；
录得短也不会提前跳走。所以下表「预留」只是当前占位时长，可以按表演需要拉长。

## 五、接线方式（已实现，无需再改代码）

1. `DialogueFlow` 在 `_ready` 建三条通道：`Voice`（台词）、`Sfx`（音效）、`Ambient`（底噪），全部走 Master，
   顶部「静音」按钮直接静音 Master。
2. 台词 id 在 `_resolve_cue("voice", id)` 里拼成 `voice.root + voice.cues[id]`；也接受直接写 `res://` 路径。
3. 事件里的低声台词（「同学，你的笔。」等）走 `Voice` 通道并显示字幕；环境音走 `Sfx` 通道，只出声不占字幕。
   `events.<id>.voice` 可以是单条对象，也可以写成**数组**按顺序播多句（捡笔事件就是「同桌递笔 → 我道谢」两句）；
   每句各自带 `speaker` / `text` / `at` / `seconds` / `cue`，同一 `Voice` 通道下时间窗不要重叠。
4. 交互里没有「等音频结束」的硬编码：时长由音频长度反推，所以补录、改语速都不用动流程。

处理方式（脚本不进仓库，只留结果）：

- 解码：PyAV 读 AAC 48 kHz 立体声 → 单声道 48 kHz。
- 裁剪：按 −45 dBFS 包络找首尾语音，句首留 0.15s、句尾留 0.25s。原文件前面常带十几秒纯静音，不裁会让每个节拍空等。
- 滤波：80 Hz 一阶高通，去掉低频隆隆声。
- 电平：峰值归一到 −3 dBFS。
- 编码：Ogg Vorbis（`libvorbis` q5），单声道 48 kHz。
- 切分：「放弃当然也能说出放弃的道理……」那条含两句追问，按 **31.35s** 切成 `followup_1` / `followup_2`（切分后两条时长 6.76s / 8.16s，与清单预留的 6.8s / 8.1s 吻合）。

两个坑：

- **Godot 4.6 的 `.ogg` 导入器只认 Vorbis**，Ogg Opus 会报
  `Ogg Vorbis decoding failed` 并留下 `valid=false` 的 `.import`；遇到这种残留要连
  `.import` 和 `.godot/imported/<name>.ogg-*` 一起删掉再导入，否则一直加载失败。
- 这批是 **AI 生成音频**（不是真人录音），生成时自带教室底噪，不是干净棚录；与 `sfx.murmur_loop` 叠加时注意音量，
  需要做总线平衡的话见上一节「混音」。
