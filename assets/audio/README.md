# 音频目录

台词与音效按 `content/classroom_dialogue.json` 的 `voice.cues` / `sfx.cues` 命名后放进对应目录即可自动生效，
不需要改脚本（同一事件要按时间播多句台词时，`events.<id>.voice` 写成数组即可，见 `docs/配音接口-2026-10-25.md` 第十一节）。

- `voice/`：老师、我、同学、旁白的台词（`.ogg` / `.wav`）
- `sfx/`：环境音与音效（`.ogg` / `.wav`），其中 `murmur_loop.wav` 从进入教室第 0 步循环到进入第二层，背景音量 −26 dB

完整清单、命名、时长策略与验收方式见 `docs/配音接口-2026-10-25.md`。
`voice/` 里现有 13 条台词：2026-11-01 入库的老师/主角 8 条（VOICE-001）、2026-11-04 入库的同学 3 条（VOICE-002），以及 2026-11-08 入库的捡笔两句同桌递笔 / 我道谢（VOICE-003）。
`sfx/` 里现有 6 条音效：2026-11-04 入库的 4 条（SFX-001：轻翻页、笔落地、课堂恢复、议论循环），以及 2026-11-08 入库的 2 条（SFX-002：松口气的叹气、两声低笑）。2026-11-04 曾按反馈移除的低笑音轨，已按用户提供的新素材恢复；`pencil.ogg` 与其余台词/L2 配音仍缺失。L1 场景描述旁白已于 2026-11-08 按用户要求移除，不再补录。
缺失时流程按预留时长继续，不会报错。
