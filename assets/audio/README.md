# 音频目录

台词与音效按 `content/classroom_dialogue.json` 的 `voice.cues` / `sfx.cues` 命名后放进对应目录即可自动生效，
不需要改脚本。

- `voice/`：老师、我、同学、旁白的台词（`.ogg`）
- `sfx/`：环境音与音效（`.ogg`），其中 `murmur_loop.ogg` 为选择时段的循环底噪

完整清单、命名、时长策略与验收方式见 `docs/配音接口-2026-10-25.md`。
`voice/` 里现有 8 条台词（第 0/1/2/4/5/7 步，2026-11-01 入库，来源见 `docs/素材登记.md` VOICE-001）；
其余台词与全部音效仍缺失，缺失时流程按预留时长继续，不会报错。
